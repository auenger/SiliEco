# 网页反馈工具：桌面端首版

目标：在独立 Tab 内访问网站，收集元素、区域和截图反馈，交给现有智能体对话分析需求并创建普通 task；手动创建作为可选入口。

## 第一版使用

已实现桌面端 MVP。运行 `pnpm dev:desktop`（涉及原生层修改时需要重启桌面进程），在 Tab 栏原有加号旁点击地球图标，打开网页反馈 Tab。输入网址或 `localhost:端口`，选择元素/区域或截图，点击“交给智能体”。截图、标记、定位和备注会带入独立的对话草稿；发送后由智能体追问必要信息、整理需求并创建 task。未采集时，此入口会先自动截图。

地址栏右侧集中放置打开网页、选元素、框选区域和截图图标。需求面板默认收起，最右侧图标控制展开/收起；采集成功后自动展开，收起时保留草稿。工具栏固定高度，进入采集状态不会挤压网页视口；采集前等待宿主布局与原生边界同步，避免错误提示消失导致截图失效。

每个会话最多保留 30 条反馈，同时最多打开 12 个原生网页实例。截图编辑首版支持矩形标记与撤销。网页标题用于区分 Tab；未提交文字、定位和标记按账号/工作区/会话持久化，截图存放于应用数据目录下的 `page-feedback/`。

右侧只需可选的一句话备注，不要求填写 task 标题。手动标题与创建按钮收纳在“手动创建（可选）”中。原图保留在本机，提交时生成并上传包含标记的 PNG；结构化证据另存 JSON 附件。

智能体入口沿用现有 ChatInput 的发送、失败重试和运行机制。每个浏览器会话有独立对话，保留当前普通对话与未发送草稿；重复交接同一份证据只打开原对话，新增备注或标记会追加新的上下文。对话提示要求需求明确后创建未分配的 Backlog task，返回链接，不直接开始代码实现。浮动对话关闭的用户会进入现有 Chat 页面。网页在浮动对话左侧继续显示，右下角入口也保留可点击空间。

## 模块边界

- `apps/desktop/src/main/browser/`：独立 WebContentsView、固定 IPC、网页选择脚本、截图文件。外部网页没有宿主 preload，与应用会话隔离。
- Desktop platform：工具路由、视图区域同步、Tab 生命周期桥接。现有 Tab 路由与新建按钮保持原行为。
- `packages/core/page-feedback/`：协议、按账号/工作区/会话隔离的持久草稿、描述生成、提交编排、Agent 对话准备与附件上传。
- `packages/views/page-feedback/`：网站工具栏、反馈编辑、截图矩形标注、需求编辑与提交。通过接口调用浏览器，不依赖 Electron。
- 不新增后端实体或迁移；复用 task 和附件 API。普通任务创建草稿不受该模块操作影响。

## 首版闭环

1. Tab 栏独立入口新建网页反馈会话，输入 HTTP/HTTPS 地址。
2. 浏览、后退、前进、刷新；Tab 切换隐藏网页，关闭销毁网页。
3. 点选 DOM 元素、框选区域、捕获当前视口；跨 frame / Canvas 使用区域反馈。
4. 原图保存在本机模块目录；草稿只保存定位、图片 ID、矩形标记和用户说明。
5. 上传截图和结构化证据，写入独立 Agent 对话草稿；通过现有对话分析与创建 task。也可展开手动创建。
6. 上传失败保留证据和已创建的对话，重试复用已上传文件；手动任务已创建时重试修复该任务，不创建第二条。

## 隔离与验证

- 禁止非 HTTP/HTTPS 导航、远程 Node、宿主 bridge、外部页面 IPC。权限和下载默认拒绝。
- 新窗口链接在当前网页打开；需要独立窗口的 OAuth 流程不纳入首版兼容承诺。
- 切换账号销毁网页；会话按账号与工作区分区。关闭窗口和渲染器重载释放原生实例。
- 弹窗/菜单/浮层打开时隐藏原生网页，避免遮盖宿主交互。
- 导航、尺寸变化或 Tab 切换取消选择；截图前后核对定位。
- 验证协议拒绝异常输入、草稿隔离、跨工作区异步提交中止、部分成功重试、Tab 关闭清理和现有 Tab 回归。

## 后续

箭头/文字/画笔、批量拆分 task、源码映射、复杂 OAuth 弹窗、Web 端采集适配。Agent 分析依赖用户工作区现有可用的智能体，采集动作本身不会自动启动模型；用户在对话中发送后开始分析。
